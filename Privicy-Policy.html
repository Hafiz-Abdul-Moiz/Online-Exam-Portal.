Examination Security & Privacy Policy

Please read these examination regulations thoroughly before taking any assessment. SkillTester enforces zero-tolerance academic surveillance to ensure valid, merit-based certification.

🚨

STRICT WARNING: CHEATING IS NOT ALLOWED (ZERO TOLERANCE)

Kisi bhi qism ki cheating, unfair means, ya unauthorized shortcuts use karna sakht mana hai. Hamara AI Proctor Sentinel har candidate ki screen, window blur, tab-switching, aur peripheral input ko real-time monitor kar raha hai. Violation detect hone par exam foran terminate ho jayega, score 0/100 (Disqualified) kar diya jayega, aur formal penalty record database mein save ho kar Admin Panel par register ho jayegi.

🔒

1. Global Input Restrictions & Peripheral Controls

To prevent unauthorized external assistance, the following system-level restrictions are enforced across the entire portal:

Globally Blocked Mouse Right-Click (Context Menu)

Poori website par mouse ka right click completely disabled hai. Inspect Element, save image, ya inspect menu access nahi kiya ja sakta.

Globally Blocked Keyboard System Shortcuts

Alt+Tab, Esc, Windows/Command Key, F1 se F12 keys, Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+U (Source code), aur Ctrl+Shift+I (DevTools) completely locked hain.

Instant Termination Tab-Switching & Window Minimization

Exam ke dauran doosra browser tab open karna, application minimize karna, ya window focus hatana foran AI Sentinel breach count karta hai.

Strictly Prohibited Screenshots & Screen Recording

PrintScreen key, third-party screen capturing, screen recording utilities, ya mirroring devices se paper copy karna cyber offense shumar hota hai.

🛡️

2. AI Proctor Sentinel Surveillance Architecture

Active Telemetry Real-Time Focus Tracking

Sentinel continuously monitors viewport focus. If a candidate leaves the exam container, a high-priority warning is fired immediately.

Admin Synchronization Remote Administrator Kill-Switch

Admin Command Center can observe active candidates in real time and issue push warnings or terminate suspicious sessions remotely.

Forensic Logging Tamper-Proof Audit Trail

Every keystroke attempt, warning count, time-drift, and session termination is timestamped in Firebase Realtime Database for verification.
